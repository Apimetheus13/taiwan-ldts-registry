先讀這個：三層資料性質

Layer 01原文抄錄
認證編號、效期、文號、檢測名稱、檢體型態、基因數、檢測技術、用途、儀器序號，以及由檢測名稱直接判定的品牌型態。 來自官方原檔，並經雙引擎交叉驗證，可直接引用。 但請注意：官方文件本身也有誤植（見稽核紀錄）。
Layer 02本表推論
定序平台推論與平台分布統計。 認證附件只列儀器序號、不列廠牌型號，此欄由序號慣例反推，非官方資料，也未經原廠文件驗證。 對外引用務必註明為推論，且不得再由平台往下推導試劑品牌。　本版本預設隱藏此層。

    平台分布與品牌組成第二層　推論

    平台由關鍵儀器設備序號反推，非食藥署官方標示。 橫條長度代表該平台的認證項目數，列與列之間可直接比較；條內的深淺分段是品牌組成。 點任一列展開實驗室名單與各自的項目數。

    A 原廠指名 B 自有品牌 C 泛稱描述 家數 ｜ A / B / C 項數 ｜ n = 該平台項目數

    兩個必須知道的限制。其一，同一個認證項目若同時用到多個平台，會在多列各出現一次（共 26 項如此）， 因此 n 值與家數縱向加總都會大於實際總數（198 項、32 家）。橫列可讀，縱欄不可加總。 其二，最後一列「無法由序號判定」不是平台，只表示儀器序號不符合任何已知編碼慣例， 故不繪製橫條、不列入長度比較；該群共 76 項，其中 62 項同時也是泛稱描述——多為單基因 qPCR 或 Sanger 檢測， 既無平台辨識度也無品牌辨識度。
