# 台灣 LDTs 認證實驗室總覽

衛福部食藥署《特定醫療技術檢查檢驗醫療儀器施行或使用管理辦法》下，
「精準醫療分子檢測實驗室認證」名單的逐項整理。

**線上閱覽**：（啟用 GitHub Pages 後填入網址）

- 32 家經認證實驗室
- 198 個認證檢測項目，逐項展開
- 資料基準日：2026-08-26
- 公開版預設隱藏「平台推論」相關內容（屬本表推論，非官方標示）

係 2018 年指引下的自願性列冊，兩者為不同制度，請勿混用。

## 三層資料性質

這份整理裡的欄位不是同一種東西。引用前請先確認是哪一層。

### 第一層　原文抄錄（可直接引用）

認證編號、效期、文號、檢測名稱、檢體型態、基因數、檢測技術、檢測項目、儀器序號，
以及由檢測名稱直接判定的品牌型態。

來自官方原檔，經兩套 PDF 引擎交叉驗證。
198 列中 194 列自動驗證通過，4 列因附表逐字錯位改以原檔人工核對補齊，並個別標示。

需注意：官方文件本身也存在誤植（見網頁「名單稽核紀錄」，目前記錄 4 處）。

### 第二層　本表推論（引用須註明）

定序平台推論、平台分布統計。

**認證附件只列儀器序號、不列廠牌型號。**
此欄係由序號編碼慣例反推，非官方資料，亦未經原廠文件驗證。
對外引用務必註明為推論，且不得由平台再往下推導試劑品牌。

**本公開版預設隱藏第二層。** 平台推論、平台分布統計、序號推論規則等內容不會直接顯示，
避免被誤讀為官方事實。頁面上有「顯示推論欄位」按鈕，需要檢視時可隨時開啟，
關閉不影響第一層原文資料——198 個認證項目與全部官方欄位皆完整呈現。

### 第三層　沿用未驗證（僅供檢索）

所在地、領域、主要技術。沿用初版整理，未重新核對原檔。
用於分類與檢索足夠，不宜作為對外論述依據。

## 檔案結構

```
index.html                    線上閱覽頁（GitHub Pages 由此提供）
data/                         Excel 版本，欄位與網頁一致
archive/                      各版本存檔，檔名為資料基準日
scripts/
  parse.py                    解析 32 份認證附件 PDF → parsed_all.json
  corrections.json            人工核對補齊的附表（逐字錯位無法自動解析者）
  build_v4.py                 產生 Excel
  build_html.py               產生 index.html
UPDATE.md                     更新作業手冊
CHANGELOG.md                  版本紀錄
```

## 已知限制

1. **跨平台項目重複計數**：24 個認證項目同時用到多個平台，在平台統計中會於多列各出現一次，
   因此平台欄位縱向加總大於實際總數。橫列可讀，縱欄不可加總。
2. **「無法由序號判定」不是平台**：76 個項目的儀器序號不符合任何已知編碼慣例，
   在統計中單獨列出且不繪製橫條、不列入長度比較。
3. **試劑資訊不存在**：認證附件體例不列試劑品牌與 kit 貨號。
   198 項中僅 7 項的官方檢測名稱直接寫出第三方廠牌，其餘 191 項的試劑來源在認證文件中不可考。
